# Seguridad

## Reportar una vulnerabilidad

No publiques credenciales, direcciones de red ni información sensible del laboratorio en un issue. Reportá vulnerabilidades mediante un aviso privado de seguridad de GitHub.

## Seguridad física

Este software puede enviar comandos a un robot real. Probalo primero en simulación. Para ensayos físicos, mantené un mecanismo de parada accesible, despejá el área, limitá la velocidad y no operes el robot sin supervisión. Los modelos y nodos se ofrecen sin garantía; quien realiza el ensayo es responsable de validar la configuración, los marcos de coordenadas y los límites del hardware.
